# SadeceMatematik - Personal Portfolio & Landing Page
*(Türkçe versiyonu aşağıdadır / Turkish version is below)*

This project is a modern, responsive personal landing page designed for **Bülent Erdoğdu**, a Mathematics Teacher with over 30 years of experience. It is optimized for users to get information about private tutoring, read references, and contact directly via WhatsApp.

## 🚀 Features

- **Modern and Clean Design**: A professional, user-friendly interface that builds trust.
- **Fully Responsive**: 100% compatible with mobile, tablet, and desktop devices using CSS Flexbox and Grid.
- **WhatsApp Integration**: "Get Private Lesson" buttons, contact form, and a floating WhatsApp icon that redirects users to the WhatsApp message screen with a single click.
- **Interactive Animations**:
  - Smooth Scrolling for internal links.
  - Number counter animations (Statistics in the Hero section).
  - Infinite Loop references slider.
  - Mobile-friendly animated Hamburger Menu.
- **High Performance**: Built entirely with Vanilla technologies without any heavy libraries or frameworks.

## 🛠️ Technologies Used

- **HTML5**: Semantic and accessible structure.
- **CSS3**: Custom animations, Flexbox/Grid layouts, and Media Queries.
- **Vanilla JavaScript**: DOM manipulation, event listeners, custom animation logic, and form handling.

## 📁 Project Structure

```bash
SadeceMatematik/
│
├── index.html       # Main HTML structure
├── style.css        # Styles, animations, and responsive rules
├── script.js        # Scroll effects, counters, menu, and form logic
└── resimler/        # Images and icons used in the project
```

## 💻 Setup & Run

Since the project consists entirely of static files, it doesn't require any server setup or package manager.

1. Clone the repository:
   ```bash
   git clone https://github.com/nustafanert/SadeceMatematik.git
   ```
2. Open `index.html` in any modern web browser.

# SadeceMatematik - Kişisel Portfolyo ve Tanıtım Web Sitesi

Bu proje, 30 yılı aşkın deneyime sahip Matematik Öğretmeni **Bülent Erdoğdu** için tasarlanmış, modern ve duyarlı (responsive) bir kişisel tanıtım web sitesidir. Kullanıcıların özel ders hizmetleri hakkında bilgi alabilmesi, referansları inceleyebilmesi ve doğrudan WhatsApp üzerinden iletişime geçebilmesi için optimize edilmiştir.

## 🚀 Özellikler

- **Modern ve Temiz Tasarım**: Ziyaretçilere güven veren, profesyonel ve kullanıcı dostu arayüz.
- **Tam Duyarlı (Responsive) Yapı**: Mobil, tablet ve masaüstü cihazlarla %100 uyumlu görünüm. 
- **WhatsApp Entegrasyonu**: "Özel Ders Al" butonları, iletişim formu ve sabit WhatsApp ikonu sayesinde tek tıkla mesaj ekranına yönlendirme.
- **Etkileşimli Animasyonlar**: 
  - Sayfa içi pürüzsüz kaydırma (Smooth Scrolling).
  - Sayı sayaç animasyonları.
  - Sonsuz döngülü (Infinite Loop) referanslar kaydırıcısı.
  - Mobil uyumlu animasyonlu Hamburger Menü.
- **Performanslı ve Hafif**: Tamamen Vanilla teknolojiler ile geliştirilmiştir.

## 🛠️ Kullanılan Teknolojiler

- **HTML5**: Semantik sayfa yapısı.
- **CSS3**: Özelleştirilmiş animasyonlar, Flexbox/Grid yapısı ve medya sorguları.
- **Vanilla JavaScript**: DOM manipülasyonu, olay dinleyicileri ve form işlemleri.
